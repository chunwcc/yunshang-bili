0这次改的是什么

上一版 vertical-feed.html 的架构方案不变（单 XComponent、换源、预取、心跳、弹幕）， 这一版只重做关灯覆盖层：把原来的「全屏视频 + VideoControls」换成 内嵌视频卡 + 三组沉浸光感胶囊。视频卡四周露出模糊的背景，胶囊浮在背景上， 也就是你手绘的布局。

4交互与状态

  • 上滑 / 下滑：切换视频；视频卡跟手，顶部胶囊与背景同步换；底部胶囊固定。
  • 轻点视频卡：暂停 / 继续；暂停时显示中央播放键，播放时隐藏。
  • 左上关注：已关注 = 绿色对勾；未关注 = 粉色「关注」胶囊。
  • 右上三连：点赞变粉、投币变金、收藏变橙；数字即时增减。
  • 返回：开灯回到详情（或退出沉浸流）；全屏：交给现有全屏分支。
  • 弹幕开关：隐藏/显示视频卡上的弹幕；按钮点位开=绿、关=灰。
  • 评论区：半屏评论 sheet；发弹幕：输入面板，发送后立即上屏。
  • 首帧：自动播放；本稿默认暂停以展示中央播放键（对齐手绘）。

6风险

  • 单 Surface：卡片里仍然只有一个 XComponent；上滑只换源，不挂第二个播放器。
  • 胶囊与手势：顶部/底部胶囊在视频卡之外，滑动只绑卡片；卡片信息层 hitTestBehavior(None)。
  • 全屏：点全屏走现有 toggleFS，feed 覆盖层在 fs 时隐藏；退出全屏再恢复，别让两套布局同时活。
  • 弹幕画布：只覆盖视频卡；显示区域收在卡片上部，别压到底部标题。
  • 心跳：换条前按 >=5s 规则落库；ct/lastHeartbeatTime 归零，别把上一条的秒数带过去。
  • HDS 降级：老机/非 API 26 材质走 ADAPTIVE；胶囊靠 tint + 描边 + 阴影保证可读，不能只靠玻璃。
  • 评论区：半屏 sheet 会顶起键盘；输入框要 keyboardAvoidMode，别复用「全屏评论浮层」的开关。
